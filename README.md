# Lucidity 2.0 (26.3 Port)

This is an unofficial port of the [Lucidity 2.0](https://github.com/hotpad100c/lucidity2.0) mod to Minecraft 26.3 (Fabric).

This entire port was made by AI.

Original mod by [Ryan100C / hotpad100c](https://github.com/hotpad100c/lucidity2.0).

## Dependencies

- Fabric Loader
- Fabric API
- MaLiLib
- Ryan's Rendering Kit

## Building

```bash
./gradlew :26.3:assemble
```
